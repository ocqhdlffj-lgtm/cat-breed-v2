고양이 품종 분류기 v2

사진 한 장으로 고양이 품종을 알아보는 프로젝트

프로젝트 소개

이 프로젝트는 고양이 사진을 입력받아 품종을 예측하는 이미지 분류 모델입니다. v2에서는 기존 버전보다 분류 정확도를 높이는 것을 목표로 합니다.

현재 상태: 소개 페이지 공개 분류기 데모는 준비 중입니다.

v2 개선 목표

  • 품종별 학습 이미지 수 균형 맞추기
  • 데이터 증강(회전, 밝기, 좌우 반전)으로 일반화 성능 높이기
  • 사전학습 모델 기반 전이학습 적용
  • 혼동이 잦은 품종 쌍 분석 후 보완

지원 품종 (예시)

실제 지원 품종은 모델 학습 결과에 맞춰 수정됩니다.
